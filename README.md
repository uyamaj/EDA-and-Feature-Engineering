# EDA and Feature Engineering

A collection of exploratory data analysis (EDA) and feature engineering notebooks 
applied to a variety of real-world datasets. Covers data cleaning, handling missing 
values and outliers, encoding techniques, imbalanced data handling, and dataset-specific 
EDA leading into feature preparation for modeling.

## Key Techniques Covered
- Handling missing values and outliers
- Encoding: One-Hot, Label, Target-Guided Ordinal
- Handling imbalanced datasets
- Univariate, bivariate, and multivariate analysis
- Feature scaling and transformation
- Correlation analysis and visualization

## Tech Stack
- Python
- pandas, numpy
- matplotlib, seaborn
- scikit-learn
- Jupyter Notebook

## How to Use
1. Clone the repository
2. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
3. Open any `.ipynb` file in Jupyter Notebook to explore that dataset's analysis
